Real artifact verification

Inspect a JSON or CSV artifact against explicit structural rules. Preview is payment-free. For a bounded agent workflow, start one confirmed run to verify, save the task, and request a single sandbox capture only for a newly recorded PASS; REVIEW and FAIL never trigger capture.

MAX 20 KB

The agent workflow requires confirmation before it starts. It never retries a previously recorded task automatically; inspect the task and use the separate capture control only when appropriate.

ⓘ Structural PASS means only that the configured rules passed. It does not prove business correctness or factual truth. Artifact task records keep the file digest and up to three preview rows, not the full uploaded content.

Independent data verification

Freeze the buyer's source dataset and acceptance contract first. The worker then submits output separately. The server independently checks record coverage, protected source fields, and deterministic calculations before a task is eligible for capture.
